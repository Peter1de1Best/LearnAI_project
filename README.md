## Contents

Currently:

### `RuleBasedChatbot`
- A C# rule-based chatbot experiment exploring:
  - console-based conversation flow
  - input normalization
  - keyword detection
  - intent detection
  - conversation turns
  - basic response handling
  - experimenting with separation between input collection, analysis, and response generation, within a very limited number of .cs files
 
The project is intentionally kept relatively simple while the architecture is still evolving.
